# Flipkart Sales Dashboard

# Project Overview

The Flipkart Sales Dashboard is an interactive Power BI project developed to analyse sales performance, profitability, orders, and quantity across different business dimensions.

The dashboard provides a clear view of sales trends and helps identify key business performance drivers.

# Technologies Used

- Power BI
- Power Query
- DAX

# Key Features

- Total Sales analysis
- Profit analysis
- Total Orders
- Quantity Sold
- Profit Growth
- Sales analysis by:
  - Category
  - Subcategory
  - Region
  - Customer
  - Payment Mode
  - Time Period
- Interactive slicers
- KPI Cards
- Charts
- Maps
- Drill-through analysis

# Data Preparation

Raw sales data was cleaned and transformed using Power Query to improve data quality and reporting accuracy.

A Star Schema data model was designed with appropriate relationships between fact and dimension tables.

# DAX Measures

Key measures created include:

- Total Sales
- Total Profit
- Total Orders
- Total Quantity
- Profit Growth

# Business Objective

The objective of this project is to analyse sales and profitability performance and identify trends across products, customers, regions, and time periods.

# Key Insights

The dashboard can help identify:

- High-performing categories and subcategories
- Regional sales performance
- Profitability trends
- Customer purchasing patterns
- Payment mode distribution
- Sales trends over time
