
###  Adidas Sales Dashboard 
# Project Overview

The Adidas Sales Dashboard is an interactive Microsoft Excel dashboard developed to analyse regional sales, product performance, and monthly revenue trends.

The project demonstrates practical Excel data analysis and dashboard development techniques.

# Technologies Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Slicers

# Key Features

- KPI Cards
- Pivot Tables
- Pivot Charts
- Interactive Slicers
- Regional sales analysis
- Product performance analysis
- Monthly revenue analysis

# Data Preparation

Sales data was cleaned and organized to improve data quality and ensure accurate reporting.

# Excel Functions Used

- XLOOKUP
- INDEX-MATCH
- SUMIFS
- COUNTIFS
- Conditional Formatting

## 📈 Analysis Performed

The dashboard analyses:

- Regional sales performance
- Product performance
- Monthly revenue trends
- Sales distribution across business dimensions

# Business Objective

The objective of this project is to analyse Adidas sales data and provide a clear visual representation of business performance to support data-driven decision-making.

# Key Insights

The dashboard can help identify:

- High-performing regions
- Best-selling products
- Monthly sales trends
- Revenue performance
- Areas requiring further business attention
